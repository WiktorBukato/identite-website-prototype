# Identité website prototype — v0.1

Frozen review version of the Identité corporate website, September 8, 2026.

- [Open the website](https://wiktorbukato.github.io/identite-website-prototype/)
- [Version 0.1](https://wiktorbukato.github.io/identite-website-prototype/v0.1/structure/en-US/index.html)

Includes the current 26 English pages, public images and downloadable product documents. Interactive examples run locally in the browser. This is a review prototype, not the live Identité service. New-page Spanish and Portuguese translations and full mobile refinement are not part of this snapshot.

GitHub Pages serves `docs/` from `main`. The `v0.1` tag and release identify this snapshot. The repository contains the rendered public site only. Local preview: `python -m http.server 8080 --directory docs`, then open http://localhost:8080/.
